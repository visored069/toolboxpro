# Skills Reference — Installed & Ready to Use

## How to Install on a New Project
```bash
npx skills add <owner/repo@skill-name> -g -y
```
Skills are installed globally and available across all projects.

---

## Installed Skills

### 1. 3D Website Architect
- **Install:** `npx skills add deveshpunjabi/3d-website-skill@3d-website-architect -g -y`
- **Installs:** 85+
- **What it does:** Architecture guidelines for building 3D websites — scene setup, asset pipelines, performance optimization, responsive 3D layouts
- **Use when:** Building any site with Three.js, WebGL, or 3D elements

### 2. Aceternity UI
- **Install:** `npx skills add secondsky/claude-skills@aceternity-ui -g -y`
- **Installs:** 1,300+
- **What it does:** Premium UI component patterns — spotlight cards, parallax scroll, multi-layer cards, background gradients, text reveal effects
- **Use when:** Building premium SaaS or portfolio landing pages

### 3. Motion (Framer Motion patterns)
- **Install:** `npx skills add fellipeutaka/leon@motion -g -y`
- **Installs:** 42
- **What it does:** Animation patterns for spring physics, gestures, layout animations, scroll-driven effects
- **Use when:** Adding fluid motion to React or vanilla JS sites

### 4. Premium 3D Website
- **Install:** `npx skills add sickn33/agentic-awesome-skills@premium-3d-website -g -y`
- **Installs:** 33
- **What it does:** Custom WebGL shaders, post-processing (bloom, DOF, film grain), physics interactions, preloaders, device optimization
- **Use when:** Building award-winning creative sites with advanced 3D effects

### 5. Premium SaaS Design
- **Install:** `npx skills add sickn33/agentic-awesome-skills@premium-saas-design -g -y`
- **Installs:** 384
- **What it does:** Premium SaaS UI patterns — glassmorphism, gradients, micro-interactions, responsive layouts, dark mode
- **Use when:** Building any SaaS product or dashboard

### 6. Web Design Guidelines
- **Install:** `npx skills add hermeticormus/libreuiux-claude-code-skills@web-design-guidelines -g -y`
- **Installs:** N/A
- **What it does:** Core web design principles — typography, spacing, color theory, responsive design, accessibility
- **Use when:** Starting any new web project

### 7. Find Skills
- **Install:** Built-in (comes with Freebuff)
- **What it does:** Search and install new skills from the ecosystem
- **Use when:** Looking for skills for specific tasks
