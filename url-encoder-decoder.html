URL Encoder & Decoder

Encode and decode URLs for web development. Enter your URL or text below.

Learn more: Encoding vs encryption: read the Base64 explainer

URLs can only contain a limited set of characters — spaces, ampersands, question marks, hash symbols, and non-English letters must be percent-encoded before they can appear in a link or query string. This tool encodes text for safe use in URLs and decodes percent-encoded strings back to readable text.

How to encode and decode URLs

  1. Paste the text or URL fragment into the input box.
  2. Click Encode to percent-encode unsafe characters (spaces become %20, etc.).
  3. Click Decode to turn percent-encoded text back into readable characters.
  4. Copy the result with one click.

URL encoding example

A space becomes %20 and & becomes %26 because & separates query parameters — without encoding, anything after an unencoded & would be treated as a new parameter. This is the difference between a link that works and one that silently truncates.

hello world&more  →  hello%20world%26more

Frequently asked questions

What exactly gets encoded?

Characters with special meaning in URLs — spaces, &, =, ?, #, %, and non-ASCII letters — get percent-encoded so your value survives intact inside a single URL component.

Why do I see + instead of %20 sometimes?

HTML form submissions historically encode spaces as +. In query strings both usually work; in path segments use %20.

Is my data sent anywhere?

No. Encoding and decoding run entirely in your browser.
