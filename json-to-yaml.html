JSON ⇄ YAML Converter

Convert between JSON and YAML in both directions. Paste your data and convert — everything happens in your browser.

JSON and YAML describe the same data in different shapes: JSON is strict and bracket-heavy, while YAML trades brackets for indentation so config files stay readable. This tool converts in both directions — paste JSON to get clean block-style YAML for a config file, or paste YAML to get JSON an API can accept. The conversion runs entirely in your browser; nothing is uploaded.

How to convert JSON to YAML

  1. Paste JSON into the input box — or switch the toggle to YAML → JSON first.
  2. Click Convert. In JSON → YAML mode you get block-style YAML with 2-space indentation.
  3. In YAML → JSON mode the parser handles nested mappings, lists, numbers, booleans, nulls, and quoted strings.
  4. Click Copy output to copy the result to your clipboard.

JSON to YAML example

This JSON:

{"service": "api", "replicas": 3, "features": ["cache", "metrics"], "debug": false}

becomes this YAML:

service: api
replicas: 3
features:
  - cache
  - metrics
debug: false

Frequently asked questions

Which YAML features are supported?

Plain mappings, lists, nested structures, numbers, booleans, nulls (~ or null), and quoted strings — the everyday config subset. Block scalars (| and >), anchors (&), and multi-document files (---) are not supported.

Why did my YAML fail to parse?

The parser needs consistent indentation (2 spaces is standard) and one top-level document. Tabs, mixed indentation widths, and flow style with nested quotes are the usual culprits.

Is my data uploaded anywhere?

No. Both conversion directions run locally in your browser — your config never leaves your device.
